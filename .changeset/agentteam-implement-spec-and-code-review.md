Added `implement-spec-agentteam` and `code-review-agentteam`, the DSH Agent Teams forms of the spec implementation and review flows. In both, every worker is a named subagent of the caller, so a worker that goes wrong can be interrupted and steered instead of abandoned, and a reviewer can be asked a follow-up while it still holds the diff. `implement-spec-agentteam` copies the ticket graph onto the shared task board, which holds the blockers, the advisory write scopes and the owner, and reads the frontier from it: a ticket is complete when its merge landed, and the Lead completes it in the same breath, which is what unblocks its dependents. Each implementer is spawned into its own worktree cut from the integration branch tip of the moment its ticket joined the frontier, and the optional exploration pass gates the whole run, since no implementer starts before its notes exist. `code-review-agentteam` pins its range to two commit SHAs, so the reviewers read an immutable diff, and reports the two axes under their own headings. Both skills are language- and repo-neutral, so nothing in them names a specific verification command or the target repo's directory layout.
